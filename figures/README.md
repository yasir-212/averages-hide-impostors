# Figures

Numbering follows the *ACM Transactions on Privacy and Security* manuscript; the prefix S marks the online supplement. Figures 1, 3
and 4 (system overview, RAPID architecture, evaluation protocol) are diagrams drawn in the manuscript's LaTeX
source and contain no measured results.

| `fig_bars.pdf` | Figure 6: RAPID versus all eight baselines on eight metrics | `scripts/fig_ext.py` |
| `fig_retry.pdf` | Figure 7: attacker success versus number of attempts | `scripts/fig_curves.py` |

| `fig_openset.pdf` | Figure 10: unenrolled attackers, with and without the absolute check | `scripts/fig_openset.py` |

their PDFs to this folder; `gen_tables_ext.py` writes the generated tables (Tables 9, 11, S6 and S7) to `scripts/tables/`.
